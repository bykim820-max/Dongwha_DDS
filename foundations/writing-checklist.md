## 0. 30초 스캔

가장 자주 걸리는 5가지. 이것만 통과해도 문구 리뷰의 대부분이 끝난다.

- [ ] 버튼이 **동사**인가? (`확인`·`OK`가 아니라 `저장`·`거래처 등록`)
- [ ] 오류에 **다음 행동**이 있는가? (`오류가 발생했습니다` 단독 금지)
- [ ] 사용자를 **탓하지 않는가**? (`잘못 입력하셨습니다` 금지)
- [ ] 조건을 **입력 전에** 알렸는가? (Helper 먼저, Error는 나중)
- [ ] 문자열이 **하드코딩**되지 않았는가? (i18n 키로)

---

## 1. 버튼 · 액션 라벨 → [§4](./writing.md)

- [ ] 누르면 무슨 일이 생기는지 라벨만 보고 안다
- [ ] 파괴적 액션은 대상·개수를 밝혔다 (`삭제` → `주문 3건 삭제`)
- [ ] 다이얼로그 버튼이 제목의 질문에 **동사로** 답한다 (`예`/`아니오` 아님)
- [ ] 화면당 primary 1개
- [ ] 로딩 중 진행형으로 바뀐다 (`저장` → `저장 중…`, `aria-busy`)
- [ ] 아이콘 전용 버튼의 `aria-label`에도 같은 규칙을 적용했다
- [ ] 2~6자 (최대 12자)

## 2. 오류 메시지 → [§5](./writing.md)

- [ ] **[무슨 일] + [어떻게]** 가 모두 있다 ← 하나라도 없으면 반려
- [ ] 기술 용어·스택 트레이스·HTTP 코드 원문이 노출되지 않는다
- [ ] 필드 오류는 필드 아래, 폼 요약은 상단, 시스템 오류는 지속 표시
- [ ] 시스템 오류를 **Toast 단독**으로 알리지 않는다
- [ ] 색만이 아니라 아이콘 + 텍스트로도 표시한다
- [ ] `aria-invalid` · `aria-describedby` · `role="alert"` 연결
- [ ] 표준 문안([§5.3](./writing.md))에 있는 상황이면 그 문안을 쓴다
- [ ] 오류 코드는 문장 안이 아니라 별도 줄 보조 텍스트로

## 3. 안내 · 상태 문구 → [§6](./writing.md)

- [ ] Empty State가 "없음"으로 끝나지 않고 **다음 행동**을 준다
- [ ] Placeholder가 라벨을 대체하지 않는다 (예시 값만)
- [ ] 로딩 문구가 **무엇을** 기다리는지 밝힌다
- [ ] 성공은 짧은 Toast, 실패는 지속 Alert + 재시도
- [ ] 되돌릴 수 있으면 다이얼로그 대신 실행 후 `실행 취소`
- [ ] 확인 다이얼로그 본문에 영향 범위(개수·대상)와 복구 가능 여부가 있다

## 4. 문장 · 표기 → [§3](./writing.md)

- [ ] 어미 — 결과 `~했습니다` / 요청 `~해 주세요` / 라벨은 명사형
- [ ] 마침표 — 서술문에만. 제목·버튼·탭·툴팁에는 없음
- [ ] 느낌표 없음. 물음표는 확인 다이얼로그 제목에만
- [ ] 말줄임표는 `…`(U+2026) 하나 (`...` 아님)
- [ ] 숫자는 천 단위 콤마, 단위는 붙여쓰기 (`3건`·`20MB`)
- [ ] 같은 개념에 같은 단어 — [§8 용어 사전](./writing.md) 확인

## 5. 다국어 → [i18n.md](./i18n.md)

- [ ] UI 문자열 + `aria-label`·`alt`·`placeholder` 모두 키로 처리
- [ ] 문장을 `+`로 조립하지 않았다
- [ ] 수량 표현에 ICU plural을 썼다
- [ ] 날짜·숫자·통화를 `Intl`로 포맷했다
- [ ] 버튼에 고정 `width`가 없다 (2자 라벨은 영어에서 폭 최대 +80%)
- [ ] `lang` 속성과 `word-break: keep-all` 적용
- [ ] 텍스트가 이미지에 포함되어 있지 않다

## 6. 즉시 반려

아래가 보이면 논의 없이 되돌린다.

| 발견 | 이유 |
|------|------|
| `확인` · `예` · `아니오` 버튼 | 결과를 예측할 수 없다 |
| `오류가 발생했습니다` 단독 | 다음 행동이 없다 |
| `잘못 입력하셨습니다` | 사용자를 탓한다 |
| `Error:` · `null` · `500` 노출 | 기계어 |
| 이모지 · 느낌표 · 의성어 | [design.md 금지 규칙](../design.md#-디자인-금지-규칙-anti-patterns) |
| 라벨 없이 placeholder만 | 입력하면 라벨이 사라진다 |
| 하드코딩된 한글 문자열 | 번역 불가 |

## 7. 빠른 교정표

| ❌ 자주 나오는 문구 | ✅ 고친 문구 |
|--------------------|-------------|
| 데이터 없음 | 등록된 거래처가 없습니다 + `거래처 추가` |
| 입력값이 잘못되었습니다 | 이메일 형식을 확인해 주세요. |
| 처리에 실패하였습니다 | 저장하지 못했습니다. 다시 시도해 주세요. |
| 경고! 정말 삭제하시겠습니까? `예`·`아니오` | 거래처 3곳을 삭제할까요? `취소`·`삭제` |
| Loading... | 거래처 목록을 불러오는 중… |
| 로그인 하기 | 로그인 |
| 패스워드 · 메일주소 | 비밀번호 · 이메일 |
| 저장 페이지로 이동합니다! | 저장했습니다. |

## 8. 리뷰어용 한 줄

> **라벨은 동사, 오류는 해결책, 안내는 다음 행동.** 셋 중 하나라도 빠지면 되돌린다.
